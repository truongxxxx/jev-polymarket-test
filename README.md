# jev-polymarket-test

**Can Jev beat the Polymarket price?** Jev (TypeSafe AI's System One model) is being pitched as a
cheap, fast judge for prediction-market bots: scan for candidates, let Jev decide which are mispriced.
This repo measures that on resolved Polymarket markets, with the market's own price as the baseline.

Results, numbers and charts: [jev/report.md](jev/report.md) (regenerated by `jev/evaluate.py`).

## The test

For every resolved Yes/No market with at least $10k volume whose reference time
(the earlier of end date and resolution time) falls in one of six months, we record:

- the market's question and resolution rules (text),
- the last traded Yes price at least 24 hours before the reference time (`p_24h`), and 7 days before,
- how it resolved.

Jev is asked one Noul question, *"this market resolves Yes"*, in two states:

| Variant | State sent to Jev |
|---|---|
| blind | question + resolution rules |
| priced | the same plus the Yes price at T−24h, with a note on what it means |

plus a Choice question for the category (sports, crypto price, politics, ...), used to split the results.

Six months are sampled so that memorisation can be measured directly: markets resolved in
January 2025, July 2025, January 2026, April 2026, July 2026 (all before the `jev-1.13.0`
release on 2026-09-10) and 10 September – 10 October 2026 (after it).

Scoring: Brier score, log loss and AUC against the resolution, for the market price, for Jev, and for a
logistic blend of both fitted with 5-fold cross-validation; calibration curves; a paper-trade check that
buys whichever side Jev favours when it disagrees with the market by more than a threshold.

## Reproduce

Python 3.11+, `pip install typesafe-sdk numpy scipy scikit-learn matplotlib`.

```bash
# 1. markets (Gamma API, public). One month per call, ~2-10k markets each.
python data/fetch_markets.py 2026-09-10 2026-10-10 data/markets_2026-09.jsonl 10000
python data/fetch_markets.py 2025-01-01 2025-02-01 data/markets_2025-01.jsonl 10000
# ... other windows

# 2. price snapshots (CLOB prices-history, public)
python data/fetch_prices.py data/markets_2026-09.jsonl 10

# 3. Jev (needs TYPESAFE_API_KEY in .env or the environment)
python jev/make_dataset.py
python jev/run_jev.py --variant blind --dry-run
python jev/run_jev.py --variant blind
python jev/run_jev.py --variant priced

# 4. report + charts
python jev/evaluate.py
```

Jev cost for the whole run is under $2 at $0.042 per million input tokens.
Raw Jev answers are not committed; the scripts are resumable and produce your own.

## Layout

```
data/fetch_markets.py   resolved Yes/No markets from the Gamma API, one month per run
data/fetch_prices.py    Yes price 24 h / 7 d before the reference time, from the CLOB history
jev/make_dataset.py     merges the months, builds the blind and priced states
jev/run_jev.py          calls Jev (one Noul + one Choice per market), resumable
jev/evaluate.py         report.md and charts/
```
